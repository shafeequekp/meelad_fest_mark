{% comment %} Reusable full-page skeleton loader — include once per page (the shared footer include already brings it in on most pages). How it works ------------ * The skeleton starts HIDDEN, so fast page loads (< 250ms) never show it. * A timer reveals it only if the page is still loading after REVEAL_DELAY = 250ms (tunable via data-reveal-ms on the #page-skeleton div, e.g. data-reveal-ms="600"). It covers the rest of the load and fades out on window.load. * Clicking an internal link or submitting a same-origin GET form reveals it IMMEDIATELY on the current page — a real navigation is starting and the browser is about to replace this page. * Opt a link/form out with data-no-skeleton. Manual control via window.MeeladSkeleton.show() / .hide(). {% endcomment %}
